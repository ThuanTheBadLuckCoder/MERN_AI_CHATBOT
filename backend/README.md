
# MERN AI Chatbot Backend

This is the backend for the MERN AI Chatbot application, providing intelligent chat capabilities with reference tracking and document summarization.

## Features

### Reference Tracking System

The backend now includes a comprehensive reference tracking system that:

1. **Tracks Document References**: For each chat response, the system automatically tracks which documents from Elasticsearch were used to generate the response.

2. **Gemini Summarization**: Uses Google's Gemini model to create concise summaries of referenced documents, making them more digestible for users.

3. **Reference Types**: Categorizes references into different types:
   - `documentation`: General documentation
   - `code_example`: Code examples and snippets
   - `component`: UI components and templates
   - `api_reference`: API documentation
   - `style_guide`: Styling and design guidelines
   - `best_practice`: Best practices and recommendations

4. **Reference Storage**: References are stored both:
   - In the conversation's message history (for persistence)
   - In global memory (for real-time access)

### API Endpoints

#### Chat Endpoints
- `POST /chat/new-basic` - Basic chat with Google Gemini
- `POST /chat/new-gpt` - Chat with OpenAI GPT and reference tracking
- `POST /chat/new-gpt-3.5` - Chat with OpenAI GPT-3.5
- `GET /chat/all-conversations` - Get all user conversations
- `GET /chat/:conversationId` - Get messages for a specific conversation
- `GET /chat/:conversationId/references` - Get references for a specific conversation

### Reference Data Structure

Each reference contains:
```typescript
interface Reference {
  id: string;                    // Unique reference ID
  type: ReferenceType;           // Type of reference
  title: string;                 // Reference title
  description: string;           // Summarized description
  originalCode?: string;         // Original code (if applicable)
  source?: string;               // Source file or URL
  relevanceScore?: number;       // Relevance score (0-1)
  usedAt: Date;                  // When the reference was used
  documentId?: string;           // Elasticsearch document ID
  summarizedContent?: string;    // Gemini-generated summary
}
```

### How It Works

1. **Query Processing**: When a user sends a message, the system performs a hybrid search (vector + keyword) to find relevant documents.

2. **Reference Generation**: For each relevant document found:
   - Determines the reference type based on content
   - Extracts a title and any code snippets
   - Uses Gemini to generate a concise summary
   - Calculates a relevance score

3. **Reference Storage**: References are stored in both:
   - Global memory for immediate access
   - Database for persistence across sessions

4. **Response Generation**: The AI generates a response using the retrieved context, and the references are attached to the response.

5. **Frontend Access**: The frontend can access references through:
   - Individual message references
   - Conversation-level aggregated references
   - Dedicated reference endpoint

### Configuration

The reference tracking system uses:
- **Elasticsearch**: For document storage and retrieval
- **Google Gemini**: For document summarization
- **OpenAI GPT**: For response generation
- **MongoDB**: For conversation and reference persistence

### Environment Variables

Make sure to set these environment variables:
```env
ELASTIC_INDEX=your_elasticsearch_index
GOOGLE_API_KEY=your_gemini_api_key
OPENAI_API_KEY=your_openai_api_key
```

## Installation and Setup

1. Install dependencies:
```bash
npm install
```

2. Set up environment variables in `.env`

3. Start the development server:
```bash
npm run dev
```

## Usage Example

```javascript
// Send a chat message
const response = await fetch('/chat/new-gpt', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': `Bearer ${token}`
  },
  body: JSON.stringify({
    message: "How do I create a responsive navbar?",
    conversationId: "conversation-123"
  })
});

// Get references for the conversation
const references = await fetch('/chat/conversation-123/references', {
  headers: {
    'Authorization': `Bearer ${token}`
  }
});
```

The response will include references that were used to answer the question, with summaries generated by Gemini for better user understanding.
